# [KB-A-006] PrintHub A — Impression bloquée en file d'attente

**Système concerné :** PrintHub A
**Catégorie :** Support IT niveau 1/2

## Symptôme
Les travaux d'impression restent bloqués dans la file PrintHub A et ne sortent pas.

## Cause probable
Spouleur PrintHub A figé ou imprimante hors ligne.

## Résolution
1. Vérifier que l'imprimante PrintHub A est allumée et en ligne.
2. Redémarrer le service Spouleur d'impression sur le poste.
3. Purger la file PrintHub A.
4. Relancer un test d'impression via PrintHub A.

## Escalade
Escalader à l'équipe Impression si PrintHub A reste injoignable.
