# [KB-B-006] ScanPro — Scanner réseau introuvable

**Système concerné :** ScanPro
**Catégorie :** Support IT niveau 1/2

## Symptôme
Le scanner réseau ScanPro n'apparaît plus dans la liste des périphériques.

## Cause probable
Adresse IP ScanPro changée ou pilote ScanPro absent.

## Résolution
1. Vérifier l'adresse IP affichée sur l'écran du ScanPro.
2. Réinstaller le pilote ScanPro depuis le portail logiciels Client B.
3. Ajouter le ScanPro par son IP dans les périphériques.
4. Lancer une numérisation test ScanPro.

## Escalade
Escalader à l'équipe Impression/Scan si le ScanPro reste injoignable.
