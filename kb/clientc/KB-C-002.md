# [KB-C-002] ZephyrVPN — Installation du client

**Système concerné :** ZephyrVPN
**Catégorie :** Support IT niveau 1/2

## Symptôme
Un nouvel utilisateur doit installer ZephyrVPN sur son poste.

## Cause probable
Poste neuf sans client ZephyrVPN.

## Résolution
1. Télécharger ZephyrVPN depuis le portail logiciels Client C.
2. Installer ZephyrVPN avec les droits administrateur.
3. Importer le profil ZephyrVPN fourni par l'équipe Réseau.
4. Tester la connexion ZephyrVPN.

## Escalade
Escalader à l'équipe Réseau si le profil ZephyrVPN est refusé.
