# [KB-C-003] FlowDesk — Définir la priorité d'un ticket

**Système concerné :** FlowDesk
**Catégorie :** Support IT niveau 1/2

## Symptôme
L'utilisateur veut signaler une demande urgente dans FlowDesk.

## Cause probable
Méconnaissance des niveaux de priorité FlowDesk.

## Résolution
1. Créer ou ouvrir le ticket dans FlowDesk.
2. Dans le champ Priorité FlowDesk, choisir Basse, Normale, Haute ou Critique.
3. Justifier le choix « Critique » dans la description FlowDesk.
4. Valider ; un ticket FlowDesk Critique notifie l'astreinte.

## Escalade
Escalader via FlowDesk à l'astreinte pour toute priorité Critique.
