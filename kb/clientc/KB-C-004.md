# [KB-C-004] KeyCard C — Remplacement d'un badge perdu

**Système concerné :** KeyCard C
**Catégorie :** Support IT niveau 1/2

## Symptôme
Un utilisateur a perdu son badge KeyCard C et doit en obtenir un nouveau.

## Cause probable
Badge KeyCard C perdu ou volé.

## Résolution
1. Désactiver immédiatement l'ancien badge KeyCard C dans la console.
2. Émettre un nouveau badge KeyCard C avec les mêmes droits de zone.
3. Associer le nouveau KeyCard C à l'utilisateur.
4. Remettre le badge KeyCard C contre signature.

## Escalade
Escalader à la Sécurité physique pour toute perte de KeyCard C.
