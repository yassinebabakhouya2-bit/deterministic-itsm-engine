# KB0010005 - Caméra Teams noire

## Description
La caméra reste noire pendant les réunions Teams.

## Diagnostic
- Vérifiez que le cache de la caméra n'est pas fermé.
- Dans Teams, ouvrez Paramètres > Appareils et sélectionnez la bonne caméra.
- Si la caméra reste noire, passez à l'étape 4.
- Redémarrez le poste.
